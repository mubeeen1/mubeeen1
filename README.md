### 🚀 Featured Projects

**[LDLR Variant Prioritization Pipeline](https://github.com/mubeeen1/LDLR-Variant-Prioritization)**
End-to-end automated CLI pipeline that extracts unclassified variants (VUS) from ClinVar, annotates them via batch Ensembl API queries, applies mathematical pathogenicity thresholds (gnomAD < 0.0001, SIFT < 0.05, PolyPhen-2 > 0.90), and maps structural disruption onto the LDLR ligand-binding domain with PyMOL and AlphaFold. Isolated 242 high-confidence pathogenic candidates from 1,319 raw ClinVar VUS targets.

**Bioinformatics CLI Toolkit** *(being packaged)*
Modular command-line tools: `run_blast.py` (taxon filtering, hit limiting), `validate_primers.py` (CLI emulation of NCBI Primer-BLAST), an AutoDock Vina docking workflow, and an awk cheat sheet for PDB parsing.
